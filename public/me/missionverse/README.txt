MISSIONVERSE — INTEGRATED SPACE MISSION DESIGN GAME

For the complete connected experience, run the project from its main folder:
1. Open the project folder in a terminal.
2. Run: npm install
3. Run: npm run dev
4. Open the local address printed by Vite, ending in:
   /me/missionverse/Missionverse-animated.html

Do not double-click the HTML files for the integrated game. The local web
server connects the animated menu, mission library, and 3D simulator.

The mission menu, mission library, mission log, design console, and simulator
are connected. A finished flight returns to mission selection and the menu's
Mission Log stores up to 30 results in this browser.

Historical spacecraft, engines, and mission payloads are documented in
NASA_MODEL_SOURCES.md in the project root. Model availability varies: some
meshes are NASA GLBs, while others are labeled reconstructions or visual
references. MissionVerse budgets, costs, scores, and what-if packages are game
estimates, not NASA contract figures or flight-certified engineering data.
